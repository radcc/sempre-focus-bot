# sempre-focus-bot

Личный Telegram-бот «Sempre Focus»: текст/голос → разбор Sonnet → карточки в Notion
(задачи, напоминания, идеи) + агент-режим (вопросы, исправления, ресёрч), расписание
7:30/19:00, пятничная рефлексия, авто-деплой. Код деплоится на сервер как есть из
корня репозитория (`setup_server.sh`).

## ⚠️ Правила разработки (после инцидента 24.08.2026)

1. На сервере Ubuntu 26.04 → **Python 3.14**. Жёсткие пины (`==`) в `requirements.txt`
   **запрещены**, кроме `anthropic`: у части библиотек нет готовых сборок (wheels) под
   cp314, pip падает на компиляции pydantic-core (Rust на сервере нет и не будет).
2. **`anthropic==0.125.0` закреплён** — код написан под этот SDK, версия 1.0+ ломает
   соединение (проверено в проде). Миграция на 1.x — только отдельной задачей с тестами.
3. Рабочий набор, проверенный в проде 24.08: `aiogram>=3.30` (тянет pydantic 2.13+
   с готовыми сборками), `anthropic==0.125.0`, `httpx>=0.28`, `python-dotenv>=1.2`.
4. Любой хотфикс, сделанный на сервере руками/через консоль, **обязан быть немедленно
   закоммичен** в репозиторий — иначе авто-деплой затрёт его при следующем пуше
   (`git reset --hard origin/main` каждые 5 минут).
5. Перед пушем прогоняй `pip install -r requirements.txt` в чистом venv на Python той же
   версии, что на сервере, или хотя бы проверяй наличие wheels под cp314 на PyPI.

## Деплой

Push в `main` = продакшн через ≤5 минут: systemd-timer `sempre-autodeploy` делает
`git fetch` + пересборку, при неподнявшемся сервисе — авто-откат и алерт в Telegram.
Ручная переустановка через панель — только для смены секретов (`.env` доставляется
cloud-init'ом), в будни 13:00–16:00 МСК.
